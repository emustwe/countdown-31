# Countdown 31 — Gemini Project Entry Point

This repository is shared between multiple coding agents.

Before changing anything:

1. Read `AGENTS.md` and follow it as the project-wide working agreement.
2. Read `docs/AI_HANDOFF.md` for the current task state and exact next action.
3. Read `docs/AI_DECISIONS.md` before changing established architecture or UI behavior.
4. Inspect the current branch, `git status`, and the latest five commits.
5. Preserve every unrelated modified or untracked user file.

After each substantive implementation, debugging, testing, or design-decision request, update the shared handoff with `scripts/update-ai-handoff.ps1` and commit the handoff files together with the task changes. Do not repeat completed work merely because another agent performed it.

Use `docs/AI_COLLABORATION.md` for the full provider-neutral workflow.
