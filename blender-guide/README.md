# 🐮 Blender 3D Cow Animation Guide (From Scratch)

Welcome to the beginner-friendly, step-by-step master guide for creating your **3D Spinning Cow with the Dual-Stage Changing Chart Board** in Blender!

---

## 🎯 What We Are Building
1. **The 3D Character**: Ben The Cow (imported into Blender).
2. **The 3D Chart Board**: A 3D signboard held high above the cow's head.
3. **The 3D Dual-Stage Text**:
   - **Spin 1 (Frames 1–60)**: Displays **`COUNTDOWN 31`** as the cow spins $360^\circ$.
   - **Spin 2 (Frames 61–120)**: Displays **`ROUND END ROUND 31`** as the cow spins another $360^\circ$ ($720^\circ$ total).
4. **Transparent Video Export**: Ready for web/game usage with zero background.

## ⌨️ Emergency Cheat Sheet (Keep This Open!)

```
MOUSE CONTROLS:
• Middle Mouse (Scroll Click & Drag)  ➔ Orbit / Look around
• Shift + Middle Mouse (Drag)        ➔ Pan / Slide camera
• Scroll Wheel Up / Down             ➔ Zoom In / Zoom Out
• Left Click                         ➔ Select an object (Orange outline)

KEYBOARD SHORTCUTS:
• Ctrl + Z                           ➔ Undo (Fix any mistake!)
• G                                  ➔ Grab / Move object
• S                                  ➔ Scale / Resize object
• R                                  ➔ Rotate object
• I                                  ➔ Insert Keyframe (Animation)
• Spacebar                           ➔ Play / Pause animation
• N                                  ➔ Open / Close Right Sidebar (Transform Numbers)
• Tab                                ➔ Enter / Exit Edit / Type Mode
```
